# Geometría 3D interactiva

Aplicación en Streamlit que grafica en 3D un **círculo**, una **elipse** y una **recta**,
con parámetros editables desde un panel lateral.

## Cómo ejecutarla en tu computadora

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Archivos

- `app.py`: código de la aplicación.
- `requirements.txt`: librerías necesarias (streamlit, plotly, numpy, pandas).
